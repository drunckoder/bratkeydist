# bratkey

Grid hotkeys for the command card and inventory in **Warcraft III 1.31.1 (x64)**, made for DotA / IMBA / LoD.

This repository only hosts releases. The launcher's **Check for updates** button downloads them from here.

**Requirements:** Warcraft III 1.31.1.12164 (64-bit). The game exe can be `Warcraft III.exe` or `War3.exe`.

**Install:** put `bratkey_launcher.exe` and `bratkey.dll` into the game's `x86_64` folder and run the launcher.

**Update:** close the game, then click **Check for updates** in the launcher.

Play offline or on LAN: injecting into the game while on Battle.net may be treated as cheating.
